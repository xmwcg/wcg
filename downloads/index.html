六、YUM/APT 国内镜像源配置

🇨🇳 CentOS/RHEL 使用阿里云镜像

sudo sed -e 's|^mirrorlist=|#mirrorlist=|g' -e 's|^#baseurl=http://mirror.centos.org|baseurl=https://mirrors.aliyun.com|g' -i /etc/yum.repos.d/CentOS-*.repo
sudo dnf makecache

🇨🇳 Ubuntu 使用阿里云镜像

sudo sed -i 's|archive.ubuntu.com|mirrors.aliyun.com|g' /etc/apt/sources.list
sudo apt update

🇨🇳 Docker 镜像加速器

sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": ["https://registry.cn-hangzhou.aliyuncs.com"]
}
EOF
sudo systemctl restart docker
